# 记上日成官网

`planchime.com` 的独立官网源码。首页介绍记上日成的产品定位、使用方式、可靠性与隐私边界，并提供 Apple 审核需要的支持、隐私、协议、联系与账号删除入口。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## 质量检查

```bash
npm run lint
npm test
```

`npm test` 会先完成生产构建，再验证首页、Android 下载页、支持页、正式法律页面和站点地图。`npm run test:download` 可单独验证下载入口的配置门禁。

生成 GitHub Pages 使用的静态产物：

```bash
npm run build:static
```

## 发布规则

- 每次同步通过独立分支和 Pull Request 进入 `main`。
- 生产站点使用 GitHub Pages 的公开静态产物；保留 Sites 构建作为可迁移的托管方案。
- `planchime.com` 只添加 GitHub Pages 所需的网站记录，根域和 `www` 最终都应跳转到 HTTPS 主站。
- 现有企业邮箱的 MX、SPF 和 `mail` 记录不得修改。
- 任何密钥、用户数据、付费资源或尚未开放的价格都不得写入仓库。

## 上线事实配置

App Store 链接、备案号和应用商店价格可通过 GitHub 仓库的 Actions Variables 在构建时注入。2026-10-17 已只读核对 Apple 中国区产品页与阿里云网站备案详情，默认采用产品 ID `6803545111` 与网站备案号 `苏ICP备2026061783号-2`；未核实的公安备案、App 备案及商品价格仍隐藏，不使用计划值补齐。

首页按平台展示入口：iOS 使用正式商店链接；小程序提供“记上日成AI”的微信搜索方法，未配置正式二维码或 URL Link；Android 保留独立下载页与关闭门禁。不得将三端写成同一发布状态，也不得把小程序描述为系统闹钟。

| Variable | 何时填写 |
| --- | --- |
| `PLANCHIME_APP_STORE_URL` | App Store 正式页面可公开访问后，填写 `https://apps.apple.com/...` 链接 |
| `PLANCHIME_ICP_NUMBER` | 取得 ICP 备案号后 |
| `PLANCHIME_PUBLIC_SECURITY_NUMBER` | 取得公安备案号后 |
| `PLANCHIME_PUBLIC_SECURITY_URL` | 取得与公安备案号对应的 `beian.gov.cn` 详情链接后；可留空 |
| `PLANCHIME_APP_FILING_NUMBER` | 取得 App 备案号后 |
| `PLANCHIME_MONTHLY_STORE_PRICE` | 月会员商品在商店创建并核对后，填写商店实际展示文字 |
| `PLANCHIME_ANNUAL_STORE_PRICE` | 年会员商品在商店创建并核对后，填写商店实际展示文字 |
| `PLANCHIME_TOP_UP_STORE_PRICE` | 补充包商品在商店创建并核对后，填写商店实际展示文字 |

价格变量必须抄录应用商店面向用户的完整展示文字，不根据内部定价计划提前填写。修改仓库变量后应重新运行“发布官网”工作流，并在公开页面核对结果。

## Android 官网下载入口

`/download/` 是固定入口。页面和 APK 是两个独立交付物；页面完成不代表 APK 已公开。当前默认显示“下载暂未开放”，不会链接旧包或测试包。

候选包事实在 `app/download/androidRelease.ts` 冻结：1.1（2）、`com.planchime.app`、ARM64、112,778,980 字节。更换安装包必须重新核验包名、版本、签名、文件大小和 SHA-256，并同时更新配置、测试与发布证据。

仅在 Local 确认生产服务、同一安装包真机验收、隐私披露与正式发布审批均通过后，才允许在**构建环境**同时提供以下非敏感配置：

| Variable | 含义 |
| --- | --- |
| `PLANCHIME_ANDROID_PUBLICATION_APPROVED` | 明确获准公开时设为 `1`，否则保持缺省 |
| `PLANCHIME_ANDROID_APK_SHA256` | 必须与上述冻结候选包的 SHA-256 完全一致 |
| `PLANCHIME_ANDROID_APK_URL` | 仅允许 `https://planchime.com` 或 `https://api.planchime.com` 下的 `/downloads/android/1.1-2/planchime-1.1-2-arm64-v8a.apk` |

以上路径是待部署约定，不是已上传地址。当前没有配置这些值，也没有修改发布工作流或上传 APK。配置校验只防止误操作，不能证明链接可用或安装包可信；上线前必须从正式 HTTPS 地址完整下载并复核字节数、SHA-256、签名、响应类型及重定向链，再用 Android 真机完成安装与升级验证。APK 应以 `application/vnd.android.package-archive` 返回并设置合适的下载文件名。校验通过后再生成指向 `https://planchime.com/download/` 的宣传二维码。

GitHub Pages 为静态站点，修改这些变量需要重新构建；目前发布工作流未接入 Android 的三个变量，正式开放时由 Local 在受控发布步骤中显式接入，不能仅在仓库设置变量后便宣称生效。保留现有托管方式，不为了新增下载页迁移域名或修改企业邮箱记录。
